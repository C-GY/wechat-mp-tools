# 自媒体内容采集工具

一个本地运行的一站式多平台内容下载与管理工具，支持微信公众号、视频号、抖音、快手、小红书、哔哩哔哩资源离线下载、RSS 订阅及视频转码。

支持桌面应用原生窗口（`pywebview`）运行，也可作为 Web 服务在浏览器中访问。

> [!TIP]
> **开箱即用，无需配置本地 Python 开发环境！**
> 本项目提供 Windows 与 macOS 双平台客户端，请从内部发布渠道获取最新版本。
### macOS 版本选择

| Mac 类型 | 下载版本 |
|----------|----------|
| **Apple Silicon**（M1/M2/M3/M4 芯片） | `ARM64` 系列产物 |
| **Intel** 芯片 | `x86-64` 系列产物 |

如果不确定自己的芯片类型，点击屏幕左上角  &#x1F5A5;  →「关于本机」即可查看。ARM64 产物无法在 Intel Mac 上运行，x86-64 产物虽然可以通过 Rosetta 在 Apple Silicon 上运行，但推荐使用原生 ARM64 版本以获得最佳性能。

## 核心功能

### 📱 微信公众号
- **文章离线下载**：支持输入公众号文章链接，完整保存正文排版（包含 HTML、高清图片、音频和视频等），支持画廊与贴图类特殊排版。
- **公众号管理**：粘贴公众号任意文章链接即可一键解析添加该公众号，浏览与按时间范围批量下载历史文章，支持文章列表一键刷新与智能重试。
- **微信读书账号池与全自动深度保活**：
  - 页面直接扫码登录，无需弹出外部浏览器窗口。
  - 支持绑定多个采集账号，系统自动轮询调度。
  - **自定义中转服务与指纹防拦截**：支持配置自定义中转平台地址，底层采用 TLS 指纹模拟技术（`curl_cffi`）杜绝握手拦截。
  - **无头浏览器会话深度保活**：支持独立 Playwright Profile 会话隔离与自动后台无头换新（Plan B），保持凭证长效新鲜。
  - **智能容错自愈**：Verify-First 智能探活，遇频率限制（429）自动避让并自愈恢复，失效账号自动熔断。
- **RSS 订阅与自动同步**：支持为公众号开启定时自动增量拉取，并输出标准 RSS 2.0 Feed。

### 🎥 微信视频号
- **单视频解析下载**：粘贴分享链接即可快速解析并无水印下载视频。
- **博主作品采集**：支持收藏博主、获取作者主页作品列表，支持一键批量下载。
- **创作者收藏备份**：作者主页的“导出配置”将全部收藏信息保存为 JSON（作者 ID、昵称、头像、关联链接、收藏时间及扩展字段），文件位于下载目录的 `channels/exports/`，导出后自动打开位置。“导入配置”选择该 JSON 即可恢复，按作者 ID 合并去重，保留现有收藏；也支持导入原始 `channels_favorites.json`。配置备份不包含作品列表和视频文件，Excel 导出仍用于查看作品数据。
- **关注列表一键增量采集**：一键同步并增量采集所有已关注博主的作品，自动跳过已下载内容。
- **本地历史自动同步**：自动扫描本地已下载文件，智能补全下载历史记录。
- **品创中枢系统**：支持配置 MySQL 8、多个北京时间触发点和飞书机器人，按创作者逐个完成环境检查、作品全量刷新、OSS 增量上传和数据库写入/更新，并提供持久化进度看板。
- **广策中枢系统**：完整沿用品创中枢的 MySQL 快照同步、每日定时、暂停/继续、飞书通知、进度看板和配置导入导出功能，使用独立配置和运行历史，数据库名称默认留空，需手动填写。
  - 环境检查分别确认原生微信内置浏览器是否存在、视频号采集连接是否就绪；已存在的浏览器不重复打开，最小化时只恢复原窗口。连接未就绪会提示在现有窗口打开或刷新视频号，只有浏览器不存在时才点击入口。手动检测与定时同步使用同一逻辑。
- **创意雷达系统**：沿用品创中枢的定时、视频号环境检查、创作者刷新、OSS 上传、暂停/继续、飞书通知和进度看板，通过 API 同步视频数据。两套系统的配置与运行记录分别保存。
- **同步模块配置备份**：品创中枢、广策中枢和创意雷达页面均提供“导出配置”和“导入配置”。导出将已保存的连接、定时、飞书配置（包含密码、API Key 和机器人密钥）复制为 JSON 到剪贴板；导入在文本框粘贴 JSON，校验通过后替换并保存当前模块配置。配置备份会校验模块类型，共用的 OSS 配置由 OSS 配置页单独管理。作者主页仍通过 JSON 文件导出和导入收藏备份。

### 🎵 抖音
- **单视频与图集无水印解析**：支持单条视频与图集内容一键无水印下载，提供直链提取、新标签页播放与文案一键复制。
- **喜欢/点赞列表智能穿透**：
  - 支持查看与批量下载当前登录账号的点赞视频，即使喜欢列表设置为「仅自己可见（私密）」亦可无感获取。
  - 支持输入任意公开博主的 `sec_uid` 或主页链接，一键获取他人公开点赞列表。
  - 支持物理滚动无限翻页采集与本地增量去重。
- **全能收藏体系 (`collect` & `collectmix`)**：
  - **全部收藏单视频**：直接拉取个人全部收藏视频列表。
  - **分类收藏夹**：支持获取自定义收藏夹分类列表及每个收藏夹下的专属视频。
  - **收藏合集列表**：支持获取已收藏的合集/播单列表（`collectmix`）。
- **双通道风控自愈机制**：
  - 针对抖音 `ArgusSecurityPlugin` 动态 `uifid` 与 `x-secsdk` 风控拦截，实现「HTTP 直连 + Playwright 会话沙箱」自动容灾自愈降级，100% 稳定穿透。
  - 扫码登录自动初始化个人主页与收藏会话，全自动提取与同步新鲜安全凭证。
- **直播间与回放解析**：支持抖音直播间实时解析（状态、清晰度列表、主播信息）以及博主历史直播回放列表采集。
- **搜索博主信息增强**：多线程并发补全搜索结果中的博主作品数、粉丝数与获赞数据。

### ⚡ 快手
- **高清视频解析下载**：支持快手单视频、图集无水印解析与批量采集。
- **流式断点续传与重试自愈**：支持网络异常中断自动重试与 Range 断点续传，保障大文件下载稳定可靠。

### 📕 小红书
- **单篇笔记解析**：支持粘贴小红书图文/视频链接，无水印下载高清图片、视频及 Live 实况图，导出文案文本与离线网页。
- **智能视频流挑选与容灾**：自动优先挑选通用兼容性最佳的 H.264 编码最高清视频轨，支持多候选 CDN 自动重试降级下载。
- **博主主页深度采集**：支持 SSR 状态与页面 DOM 智能混合提取首屏笔记，配合网络接口拦截与物理滚动，完整采集博主所有笔记作品。

### 📺 哔哩哔哩
- **单视频与多分P下载**：支持 BV/AV 号、番剧及多分P视频解析，批量下载指定分P。
- **UP主空间投稿采集**：收藏 UP 主或输入空间链接，一键获取投稿列表并批量下载。
- **音视频无损混流**：自动下载最高清画质音视频轨，并使用本地 FFmpeg 自动混流为完整 MP4。
- **弹幕与字幕提取**：支持将弹幕转为 ASS 格式，支持提取 CC 字幕并转为 SRT/ASS 格式。

### 🎬 视频转码与空间优化
- **全格式兼容**：支持 MP4、MKV、MOV、WebM、AVI、FLV、TS 等视频格式互转，以及提取 MP3 音频。
- **一键智能扫描**：自动递归扫描微信视频号与抖音所有已下载媒体，支持一键批量转码与拖拽导入。
- **硬件加速与压缩比对**：支持 H.264/H.265 编码与硬件加速，实时计算转码前后体积比对与空间节省百分比。
- **环境自愈**：自动探测加载系统与内置 FFmpeg 环境，缺失时支持一键自动下载配置。

```bash
# 1. 进入源码目录
cd videoDownloadTools

# 2. 安装依赖
pip install -r requirements.txt
playwright install chromium
```

## 数据目录说明

- **macOS**：`~/Library/Application Support/WeChat MP Tools/data/`
- **Windows / Linux**：程序同级目录下的 `data/`
- 包含登录凭据、独立浏览器 Profile 缓存、收藏博主/公众号数据、下载历史记录及下载文件。
- 品创中枢、广策中枢、创意雷达与 OSS 凭据另存于当前系统用户配置目录，覆盖安装或升级应用不会清除这些配置。

### 视频号环境检查与故障日志

- “同步助手运行中”表示本地代理服务开启；定时同步还需要视频号页面在本次检查开始后返回有效采集心跳。仅有旧心跳或微信进程不能视为采集已就绪。
- 环境检查先恢复已识别的最小化视频号浏览器，等待最多 20 秒。未收到心跳时重新检查窗口，并额外等待最多 8 秒；期间新识别到的最小化浏览器也会恢复。已有内置浏览器时不会重复点击微信的视频号入口。
- 页面心跳请求设置 5 秒超时，超时或中止后释放轮询锁并继续轮询；网络恢复、页面重新显示时也会主动发送心跳，避免一次请求卡住后永久停止上报。
- 自动打开微信报错后，再等待最多 8 秒核验连接；如果连接已经恢复，就继续使用现有页面。仍未收到有效心跳时，手动环境检测返回带诊断编号的错误；品创中枢、广策中枢、创意雷达的同步任务则保留原批次进入“等待自动恢复”。环境检查失败后依次等待 15、30、60 秒重试，此后每次等待 60 秒，直到恢复、用户暂停或软件关闭，不逐次发送失败通知。
- 连续两次环境检查失败后，后续检查可自动刷新已识别的微信内置浏览器；同一窗口五分钟内最多尝试一次。刷新前确认目标窗口获得焦点，无法获得焦点时继续等待重试，不向其他应用发送刷新按键。浏览器不存在时仍走自动打开流程。
- 等待恢复时保存当前批次、创作者计划及已处理结果；软件重新启动后自动继续该批次，跳过已有结果的创作者并恢复计数。等待期间的新定时触发合并到当前补跑批次，采集恢复时的最新数据，不伪造断连时段的历史快照。主动暂停仍需主动继续；退出发生在上传、数据库/API 写入等其他阶段时仍保留原有中断处理。
- Windows 诊断日志位于软件 EXE 同目录的 `data/logs/channels_environment.jsonl`；源码运行时位于项目的同名路径。日志记录检查时间、诊断编号、心跳距今秒数、窗口句柄/进程/类名、恢复结果及自动打开错误，不记录窗口标题、页面 URL 或凭据。单文件达到 2 MiB 后轮转，保留 3 份旧日志。无写入权限或磁盘不可用时日志可能无法保存，但不因此中断同步。
- 页面历史保存在 `%APPDATA%/Fandow/SelfMediaContentCollector/` 下的 `pinchuang_hub_state.json`、`guangce_hub_state.json`、`creative_radar_state.json`。排查问题时可用历史中的诊断编号匹配上述日志。`wechat_mp_tools.log` 仍仅用于启动异常。
- 锁屏等情况阻止桌面操作时，任务保持等待，页面连接或可交互桌面恢复后自动补跑，无需再次点击执行。软件无法绕过操作系统锁屏或微信登录验证；真正退出登录时仍需要完成微信认证。系统不会仅凭“监控开启”就跳过连接检查。

### 广策中枢同步

左侧“微信视频号 → 广策中枢系统”可配置 MySQL 8、每日触发时间和飞书机器人。数据库名称默认留空，需填写实际库名；目标表为 `competitor_video_snapshots`，表结构和批次快照规则与品创中枢相同，需提前准备符合要求的数据库和表。

- `guangce_hub_config.json`、`guangce_hub_state.json` 分别保存广策配置与运行历史，与品创中枢和创意雷达独立。
- 新模块初始定时关闭、连接凭据为空；配置完成后可手动执行或启用每日定时。共用已有的收藏创作者、视频号环境和 OSS 配置。
- 配置导出使用独立的 `guangce_config` 类型，包含已保存的数据库密码和飞书密钥；导入模块备份时校验类型，避免误覆盖其他模块。

### 创意雷达 API 同步

左侧“微信视频号 → 创意雷达系统”填写上传接口地址、API Key，并配置每日触发时间和飞书机器人；OSS 使用现有公共配置。默认接口地址为 `http://pinguan-central-platform.fandow.com/api/external/upload`，API Key 需自行填写；已保存的 Key 留空则保留，更换地址时需填写对应 Key。

- 请求采用 `POST` JSON（`Content-Type: application/json; charset=utf-8`）：`api_key`、`source: "external"`、`videos`，每批最多 200 条。视频的 `platform` 为 `wechat_channel`，完整 ID 对应 `aweme_id`；携带标题、作者、OSS 视频链接 `video_url`、来源链接 `original_url`、封面、发布时间、时长和互动数，分享数使用 `share_count`。点赞/喜欢映射与参考项目及页面展示一致。
- 每轮刷新创作者后，全量整理已准备好的作品并顺序分批提交，不查询本机同步记录或检测字段变化；重复数据由服务端幂等处理。已有本地 OSS 视频链接直接复用，缺失链接的作品仍通过原流程上传。
- API 配置中的“同步超时（秒）”控制每批等待响应的时间，默认 600 秒（10 分钟），支持 1–600 秒，保存在 `api.timeout_seconds`；旧配置未填写时自动使用 600 秒，已保存的超时设置继续生效。同步连接超时最多 10 秒，且不超过配置值；连接测试仍为 5 秒连接、30 秒等待响应。暂停在当前刷新、上传步骤或 API 批次结束后生效。
- 接口整体返回成功即可记录批次已受理，不要求逐条返回 `inserted`、`updated` 或 `errors`。若提供有效 `errors[index]` 则记录对应作品失败；超时、请求异常或无法定位的错误记为整批结果待确认，不推断具体作品的成功/失败。批次范围、受理数、明确失败数和待确认数保存在运行记录中，页面可展开批次明细；问题批次不阻止后续批次和创作者，下轮仍全量提交。
- “测试 API 连接”使用与同步相同的 POST 请求，携带 API Key 和空 `videos` 数组。接口先校验密钥：正确密钥返回“videos 数组不能为空”，错误密钥返回 403。测试只将成功响应或这一明确的空数组校验响应视为通过，不写入测试视频。
- 若提示“目标端口拒绝连接”（Windows 错误 10061），连接尚未进入 HTTP 或 API Key 校验阶段；需检查目标服务、端口监听及防火墙规则，或确认接口是否已迁移。更换 OPTIONS/POST 请求方法不能解决 TCP 连接被拒绝的问题。
- `creative_radar_config.json`、`creative_radar_state.json` 分别保存配置与运行历史，位于系统用户配置目录，与品创中枢文件独立。旧版 `creative_radar_state_sync_cache.json` 保留但不再读写。

### OSS 存储地址

- 服务域名固定为 `https://oss.fandow.com`，配置页分别填写 `OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET` 和 `OSS_BUCKET`。存储桶保存在 `oss_config.json` 的 `bucket` 字段，Access Key 和 Secret 仅用于请求认证。
- 例如 Bucket 为 `creator-library`，新上传视频链接为 `https://oss.fandow.com/creator-library/wechat_channel/2026-09-03/视频ID.mp4`；无有效发布时间的作品省略日期目录。
- Bucket 只能包含 ASCII 字母、数字、点、下划线和连字符，且不能为 `.` 或 `..`。对应存储桶需已存在，并具备上传、校验和公开读取所需权限，软件不会自动创建存储桶。
- 配置页输入 Bucket 会实时预览地址，点击“保存配置”后生效。只更换 Bucket 可保留原 Secret；更换 ID 必须填写对应 Secret。正在上传的批次沿用启动时的配置，后续新批次读取新配置。
- 旧配置没有 `bucket` 字段时沿用原 Access Key ID 对应的桶，保存后独立记录桶名。已上传视频不会因切换桶或凭证而迁移、重传或替换链接；导出保留原地址。新上传记录保存所属桶，兼容仅有对象键的旧记录时仍使用旧固定桶。

### 品创中枢数据库：按同步批次保留视频快照

`competitor_video_snapshots` 按同步批次记录视频状态，保留历史快照：

- 唯一键为 `(platform, source_video_key, sync_batch_id)`：同一视频在同一批次最多一行，不同批次分别保存，业务字段无变化也会新增本批次快照。
- 同批次重试更新该快照的作者、标题、封面 `cover_url`、发布时间、时长、互动指标、`synced_at` 和 `raw_payload`；保留其主键、`sync_batch_id`、`created_at` 和 OSS `video_url`，不会更新其他批次。
- 每轮任务生成新的 `sync_batch_id`；暂停后继续沿用当前批次。`synced_at` 表示该快照最近一次入库/重试的时间。
- 新视频上传 OSS 后入库；已有视频按 `synced_at DESC, snapshot_id DESC` 选择最新快照并复用 OSS 链接，不重复上传。
- 每轮同步都会为已有视频写入本批次的新快照，因此下次同步会把当前采集到的 `cover_url` 写入新快照；历史批次的旧快照不会被回填或改写。
- 看板的“数据库处理”统计成功处理的快照数，包含本批次新增及同批次重试，不等于新增视频数；接口字段仍为 `database_written`。
- 连接测试和同步前检查要求完整的三字段唯一索引（不接受普通索引或前缀索引）。若同时存在 `(platform, source_video_key)` 两字段唯一索引，会停止同步，避免跨批次写入覆盖历史。已有三字段唯一索引且无冲突约束的数据库无需迁移。
